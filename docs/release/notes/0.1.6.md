# Open 0.1.6 (8)

Engine: Chromium 156.0.8078.48 · CEF 4fa4ab5. macOS 26 or later, Apple silicon.

## App icon
- Open's icon is now a native macOS 26 icon. macOS draws its shape, edge light, glass and shadow, as it does for Apple's icons. It follows the Light, Dark, Clear and Tinted icon styles.
- The other icons in Settings › Appearance › App icon now have the same shape, size and edge as Apple's icons in the Dock.
- If the Dock still shows the old icon after updating, log out and back in.

## History
- Page titles in the History list are no longer cut off, and each row shows its address again.
- Pages without an icon show a globe in the right colour for the light or dark theme.
- A long profile name fits in the filter button.

## Switching Spaces
- When you switch Spaces, the page no longer goes blank. The old page stays until the new one is drawn.

## Welcome
- The Basics page has a new layout, with short clips recorded from Open itself.
