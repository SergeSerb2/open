# Open 0.1.7 (9)

Engine: Chromium 156.0.8078.48 · CEF 4fa4ab5. macOS 26 or later, Apple silicon.

This release is mostly about reliability. We fixed more than 500 bugs across the whole browser.

## Your data is safer
- Notes and Easels no longer lose newer text when the same item is open in two places. Long Notes and Easels open again after you save them.
- Deleting a Profile keeps your archived Favorites. Undoing a new Profile removes its files.
- Opening a Blank Window no longer overwrites your saved windows and tabs.
- One folder that cannot be removed no longer stops Open from launching.
- Imports from Arc, Chrome, Firefox and Safari keep more of your data: split views, routing rules, passwords with unusual dates or rows, and Safari CSV files with quotes.
- Importing invalid shortcuts no longer erases your custom shortcuts.
- Cmd+Shift+T restores the closed tab even when the Archive changes at the same time.

## Privacy and Incognito
- Incognito windows no longer write Picture in Picture, translation, Developer Mode or download choices into your normal Profile.
- Extension popups close when an Incognito session ends or a Profile is deleted.
- Air Traffic Control rules that start with a web address no longer match look-alike sites.
- Clear Browsing Data works even when no normal window is open.
- AppleScript cannot run page JavaScript through a `javascript:` address unless you allow it.

## Quitting and closing
- Open no longer hangs on Quit when a page in a background tab asks "Leave site?".
- Closing a window or tab during Quit no longer blocks later Quits.

## Security keys and passkeys
- When a site allows both, Open shows separate choices for a USB security key and for a phone or tablet. It no longer goes straight to the phone QR code.
- The passkey sheet appears on the window that asked for it. Pressing Escape cancels the request and keeps the window open.

## Everywhere else
- The sidebar, command bar, Library, Split View, Peek, Little Open, Boosts, Site Control, Settings, Downloads and extensions all received many fixes. Most of them are cases where the screen did not update, a shortcut went to the wrong window, or a menu item was available when it should not be.
- VoiceOver reads more controls correctly.
- Open starts its background services (tab sleep, ad blocking, the updater) even if you close the first page before it finishes loading.
