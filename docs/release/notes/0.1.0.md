This is the first release of Open, a Mac browser with a sidebar for your tabs.

## Changes

- Sidebar with Favorites, Pinned tabs, folders and Today tabs. Drag tabs to pin, unpin, reorder or move them into folders. Show or hide the sidebar with ⌘S.
- Spaces with their own colors and themes. Switch Spaces from the sidebar or with keyboard shortcuts.
- Today tabs archive automatically after the time you choose. Find them again in the Library.
- Command bar (⌘T and ⌘L) to search, open sites, switch tabs and run commands.
- Split View, Peek and Little Open.
- Profiles, each with its own data.
- Link routing rules (Settings → Links) and Boosts.
- Built-in ad and tracker blocking.
- Chrome Web Store extensions, with their buttons and popups.
- Password manager: save, fill and manage passwords, cards and addresses.
- Library with Downloads, Archive, History, Media and Spaces.
- Import from Arc: Spaces, tabs, folders, bookmarks and history.
- Updates download and install from Settings → General.

## Fixes

- None. This is the first release.

## Known issues

- Import from Arc does not bring passwords and cookies yet.
- Site Control Center is not finished.
- Easels, Notes, Live Folders, calendar previews and import from Safari, Chrome and Firefox are not available yet.
- iCloud Keychain passkeys are not available. Security keys and phone passkeys work.
