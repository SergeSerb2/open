# Open 0.1.9 (11)

Engine: Chromium 156.0.8078.48 · CEF 4fa4ab5. macOS 26 or later, Apple silicon.

This release adds optional, zero-knowledge end-to-end encrypted Open Accounts and full browser syncing across Macs, along with Split View and sidebar drag-and-drop fixes.

## Accounts and browser sync
- Optional Open Accounts and real-time browser sync backed by a self-hosted TypeScript/Node.js sync server (`SyncServer/`) with a configurable server URL.
- Zero-knowledge end-to-end encryption (PBKDF2-HMAC-SHA256, HKDF-SHA256, AES-256-GCM with AAD binding) and a one-time `OPEN-XXXX-...` recovery key. Your sync server never sees your password, vault key, or browsing data.
- Syncs Profiles, Spaces, themes and icons, Favorites, Pinned tabs, Today tabs, Folders, Split Views, Live Folders, Archive, Air Traffic Control rules, portable Settings, Keyboard Shortcuts, Ad Blocking lists and allowed sites, Boosts, Easels and Notes (with encrypted image/asset blobs), Browsing History, Chrome Web Store extensions list/enabled/pinned state, Site Permissions, and Passwords & Autofill.
- New **Settings ▸ Account & Sync** section (`open://settings/account-sync/account`), Command Bar commands (`Account & Sync…`, `Sync Now`), a skippable onboarding account step, and a sidebar status banner when sync needs attention.
- Signing into an existing cloud account defaults to replacing local data with the cloud setup after saving an automatic backup under `State/SyncBackups/`, with options to merge or keep local data instead.

## Sidebar and Split View
- Fixed Split View drag routing, a `draggingEnded` crash, and multi-Space sidebar tab drops.
